# MCMC Cheatsheet

## 1. 核心动机
- **目标**：从高维复杂分布$p(z|y) = \frac{p(y|z)p(z)}{p(y)}$中抽样，尤其当解析形式不可得时。
- **问题**：高维分布（如图像像素间的后验分布）无法直接抽样，需借助MCMC。

## 2. 平稳分布 (Stationarity)
- **定义**：对于马尔可夫链转移概率$T(x, y)$，若$\sum_x \pi(x) T(x, y) = \pi(y)$，则$\pi$是平稳分布（分布随时间不变）。
- **矩阵形式**：$\pi T = \pi$。
- **存在条件**：
  - 不可约性 (Irreducibility)：任一状态到另一状态有正概率到达。
  - 正循环性 (Positive Recurrence)：返回任一状态的期望时间有限。
- **渐近收敛**：若链为不可约、正循环、非周期（即遍历链），则分布随时间趋近平稳分布。
- **可逆性**：若$\pi(x) T(x, y) = \pi(y) T(y, x)$，则链为可逆，$\pi(x)$是平稳分布。

## 3. Metropolis-Hastings (MH) 算法
- **目标**：从分布$\pi(x)$抽样，仅需未归一化形式$\tilde{\pi}(x)$。
- **步骤**：
  1. 选择易抽样的提议分布$q(x, y)$（需不可约、非周期）。
  2. 当前状态$x = Z_{m-1}$，从$q(x, y)$抽取候选$y$。
  3. 计算接受概率：$A(x, y) = \min\left(1, \frac{\tilde{\pi}(y) q(y, x)}{\tilde{\pi}(x) q(x, y)}\right)$。
  4. 若接受（概率$A(x, y)$），则$Z_m = y$，否则$Z_m = x$。
- **提议分布选择**：
  - 随机游走MH：$q(x, y) = q(y - x)$（如$N(0, \Sigma)$），接受率建议0.25~0.5。
  - 独立链MH：$q(x, y) = q(y)$，需重尾分布，接受率接近1。
- **技巧**：
  - 预热期 (Burn-in)：丢弃前1000~5000步，确保趋近平稳分布。
  - 稀疏化 (Thinning)：每隔$d$步取样，降低样本相关性。

## 4. Gibbs采样
- **目标**：从多变量分布$p(z_1, ..., z_d)$抽样。
- **前提**：能计算条件分布$p(z_i | z_{-i})$。
- **步骤**：
  1. 初始化$(z_1^{(0)}, ..., z_d^{(0)})$。
  2. 在第$k$步，依次更新：
     -$z_1^{(k)} \sim p(\cdot | z_2^{(k-1)}, ..., z_d^{(k-1)})$
     -$z_2^{(k)} \sim p(\cdot | z_1^{(k)}, z_3^{(k-1)}, ..., z_d^{(k-1)})$
     - ...
     -$z_d^{(k)} \sim p(\cdot | z_1^{(k)}, ..., z_{d-1}^{(k)})$
  3. 丢弃预热期样本。
- **特性**：是MH的特例，接受概率始终为1。
- **条件分布获取**：$p(z_1 | z_2, ..., z_d) = \frac{p(z_1, ..., z_d)}{p(z_2, ..., z_d)}$，忽略不依赖$z_1$的项。

## 5. 关键示例
- **MH示例**：目标$\pi(x) \propto \exp(-x^2) x^2 (5 + \sin(2x))$，提议$q(x, y) = N(y | x, \sigma^2)$，接受概率$A = \min\left(1, \frac{\tilde{\pi}(y)}{\tilde{\pi}(x)}\right)$。
- **Gibbs示例（Ising模型）**：图像去噪，条件分布基于sigmoid函数抽样。

## 6. 注意事项
- **MH性能**：提议分布方差需平衡，过小探索慢，过大接受率低。
- **预热期判断**：难以精确确定，通常根据经验丢弃初期样本。
- **样本相关性**：MCMC样本非独立，需稀疏化处理。

## 7. 总结
- MCMC是高维抽样利器，利用马尔可夫链平稳分布特性。
- MH通过提议和接受机制抽样，Gibbs通过条件分布更新变量。
- “MCMC让我们直接针对实际模型抽样，而非局限于数学方便形式。” —— Peter Clifford (1993)
