# 混合模型与EM算法考试备忘单

## 1. 混合模型（Mixture Models）

### 1.1 基本定义
- **混合模型**：数据$x$从$K$个概率密度函数生成：$p(x| \theta) = \sum_{k=1}^K \pi(k) p(x| \eta_k)$
- **隐变量$z$**：表示生成分布索引，$p(z) = \text{Cat}(z| \pi)$，$\sum_{k=1}^K \pi(k) = 1$
- **参数**：$\theta = (\pi, \{\eta_k: k=1, \dots, K\})$

### 1.2 高斯混合模型（GMM）
- **概率密度**：$p(x| \theta) = \sum_{k=1}^K \pi(k) \mathcal{N}(x| \mu_k, \Sigma_k)$
- **参数**：$\theta = (\pi, \{\mu_k, \Sigma_k\}_{k=1}^K)$
- **期望与协方差**：
  -$\mathbb{E}[x] = \sum_{k=1}^K \pi(k) \mu_k$
  -$\text{cov}(x) = \sum_{k=1}^K \pi(k) (\Sigma_k + \mu_k \mu_k^T) - \mathbb{E}[x] \mathbb{E}[x]^T$

### 1.3 最大似然估计（MLE）
- 对数似然：$\log p(x_1, \dots, x_n| \theta) = \sum_{i=1}^n \log \left( \sum_{k=1}^K \pi(k) p(x_i| \eta_k) \right)$
- 优化困难：对数与求和无法交换顺序

### 1.4 问题
- **奇异性**：GMM中若$\Sigma_k \to 0$，似然值趋于无穷
- **不可辨识性**：参数可排列，似然无唯一最优解

## 2. 期望最大化算法（EM Algorithm）

### 2.1 基本思想
- **目标**：最大化观测数据对数似然$\log p(x| \theta)$
- **完整数据$y$**：包含隐变量，易优化$\log p(y| \theta)$
- **迭代优化**：计算期望$Q(\theta| \theta^{(m)}) = \mathbb{E}_{p(y|x, \theta^{(m)})} [\log p(y| \theta) | x, \theta^{(m)}]$

### 2.2 算法步骤
1. **初始化**：选择初始参数$\theta^{(0)}$
2. **E步（Expectation）**：计算$Q(\theta| \theta^{(m)})$
3. **M步（Maximization）**：$\theta^{(m+1)} = \arg \max_{\theta} Q(\theta| \theta^{(m)})$
4. **重复**：直到对数似然变化小于阈值

### 2.3 EM for GMM
- **完整数据**：$y = (x_i, z_i)_{i=1}^n$，$z_i$是隐变量
- **E步**：计算责任度（Responsibility）：
 $$
  r_{ik}^{(m)} = \frac{\pi^{(m)}(k) \mathcal{N}(x_i| \mu_k^{(m)}, \Sigma_k^{(m)})}{\sum_{k'=1}^K \pi^{(m)}(k') \mathcal{N}(x_i| \mu_{k'}^{(m)}, \Sigma_{k'}^{(m)})}
 $$
  计算有效样本数：$n_k^{(m)} = \sum_{i=1}^n r_{ik}^{(m)}$
- **M步**：更新参数：
  -$\pi^{(m+1)}(k) = \frac{n_k^{(m)}}{n}$
  -$\mu_k^{(m+1)} = \frac{1}{n_k^{(m)}} \sum_{i=1}^n r_{ik}^{(m)} x_i$
  -$\Sigma_k^{(m+1)} = \frac{1}{n_k^{(m)}} \sum_{i=1}^n r_{ik}^{(m)} (x_i - \mu_k^{(m+1)})(x_i - \mu_k^{(m+1)})^T$
- **收敛性**：计算对数似然$L^{(m+1)}$，若$|L^{(m+1)} - L^{(m)}| \leq \epsilon$，则停止

### 2.4 K-Means（EM特例）
- **假设**：$\Sigma_k = \sigma^2 I$，$\pi(k) = 1/K$
- **E步**：硬分配，$r_{ik}^{(m)} = 1$若$k = \arg \min_k \| x_i - \mu_k^{(m)} \|^2$，否则为0
- **M步**：$\mu_k^{(m+1)} = \frac{1}{N_k} \sum_{i: k_i = k} x_i$，$N_k = \sum_{i=1}^n 1\{k_i = k\}$

### 2.5 MAP估计与EM
- **目标**：$\theta_{MAP} = \arg \max_{\theta} (\log p(x| \theta) + \log p(\theta))$
- **M步修改**：$\theta^{(m+1)} = \arg \max_{\theta} (Q(\theta| \theta^{(m)}) + \log p(\theta))$
- **作用**：正则化参数，避免奇异性问题

---

## 3. 关键性质
- **EM单调性**：对数似然单调不减，$l(\theta^{(m+1)}) \geq l(\theta^{(m)})$
- **局限性**：可能陷入局部最优，需多点初始化
