# 深度网络训练速查表（Cheat Sheet）

## 1. 基础概念
- **深度网络（Deep Neural Networks, DNNs）**：由多层神经元组成，用于分类、回归等任务。
- **多层感知机（MLP）**：包含输入层、隐藏层和输出层，通过权重和偏置计算特征。
- **应用案例**：手写数字识别，输入图像（例如256维），输出类别概率（例如10维）。

## 2. 网络结构与计算
- **前向传播（Feed-forward）**：输入通过各层计算输出。
  - 单层计算：$a = \sigma(Wx + b)$
  - 多层计算：依次计算各层激活值，最终输出$y = f(x)$。
- **矩阵运算**：高效处理多维数据，权重矩阵$W$，偏置向量$b$。
- **PyTorch示例**：
  ```python
  linear_1 = torch.nn.Linear(3, 4)  # 定义层：R^3 → R^4
  x = torch.randn(1, 3)  # 输入
  h1 = linear_1(x)  # 前向传播
  ```

## 3. 激活函数
| 名称             | 公式/定义                              | 输出范围       | 特点/应用                          |
|------------------|---------------------------------------|----------------|-----------------------------------|
| **Sigmoid**      |$\sigma(z) = \frac{1}{1+e^{-z}}$ | (0,1)          | 模拟神经元激发，易梯度消失         |
| **Tanh**         |$\tanh(z) = 2\sigma(2z) - 1$     | (-1,1)         | 零中心化，优于Sigmoid             |
| **ReLU**         |$f(z) = \max(0, z)$              | [0, ∞)         | 计算快，缓解梯度消失，现代常用     |
| **Leaky ReLU**   |$f(z) = \alpha z (z<0), z (z\geq0)$| (-∞, ∞)        | 解决“死亡ReLU”问题                |
| **Linear**       |$f(z) = cz$                      | (-∞, ∞)        | 用于回归输出层，输出实值           |

## 4. 输出层
- **Softmax**：多分类任务，输出概率分布。
  - 公式：$y_i = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}}$
  - 特点：输出和为1。
  - 代码：`torch.nn.Softmax()(x)`

## 5. 数据预处理
- **标准化**：数据零均值、单位方差。
  - 代码：`x_standardized = (x - x.mean()) / x.std()`
- **归一化**：缩放到[0,1]或[-1,1]。
  - 代码：`x_normalized = (x - x.min()) / (x.max() - x.min())`

## 6. 损失函数
- **分类任务**：交叉熵损失（Cross-Entropy Loss）
  - 公式：$\mathcal{L}(\theta) = -\frac{1}{N} \sum_{i=1}^N \sum_{k=1}^K y_k^{(i)} \log \hat{y}_k^{(i)}$
- **回归任务**：均方误差（MSE）
  - 公式：$\mathcal{L}(\theta) = \frac{1}{N} \sum_{i=1}^N (y^{(i)} - \hat{y}^{(i)})^2$
- **目标**：最小化总损失$\mathcal{L}(\theta)$

## 7. 优化算法
- **梯度下降（GD）**：沿梯度反方向更新参数。
  - 更新公式：$\theta_{\text{new}} = \theta_{\text{old}} - \alpha \nabla \mathcal{L}(\theta_{\text{old}})$
  - 问题：可能陷入局部最优，平坦区域慢。
- **Mini-batch GD**：小批量数据计算梯度，常见批量大小32-256。
- **SGD**：单样本梯度更新，波动大。
- **动量GD**：结合历史梯度，平滑更新。
- **Nesterov加速**：预测下一步位置计算梯度。
- **Adam**：自适应学习率，结合一阶和二阶动量，常用。
- **学习率（LR）**：步长，需调度。
  - 退火：减少LR（如指数衰减）。
  - 代码：`scheduler = torch.optim.lr_scheduler.ExponentialLR(optimizer, gamma=0.9)`

## 8. 反向传播（Backpropagation）
- **原理**：从输出到输入逆向计算梯度，基于链式法则。
- **过程**：前向传播计算损失 → 反向传播计算梯度 → 参数更新。
- **PyTorch示例**：
  ```python
  loss = loss_fn(y_pred, y)
  loss.backward()  # 计算梯度
  optim.step()     # 更新参数
  ```

## 9. 常见问题与解决
- **梯度消失/爆炸**：梯度过小/过大。
  - 解决：ReLU激活、批量归一化（Batch Normalization）。
- **欠拟合**：模型简单，训练和验证误差高。
- **过拟合**：模型过拟合训练数据，验证误差高。
  - 解决：正则化、Dropout、早停。

## 10. 正则化与改进
- **L2正则化**：惩罚大权重，$\mathcal{L}_{\text{reg}} = \mathcal{L} + \lambda \sum \theta_k^2$
- **Dropout**：随机丢弃神经元（率20%-50%），集成学习。
- **早停**：验证集性能不再提升时停止。
- **批量归一化**：标准化批量输入，缓解梯度问题。
  - 代码：`torch.nn.BatchNorm1d(num_features)`

## 11. 超参数调优
- **超参数**：层数、神经元数、学习率、正则化参数等。
- **方法**：
  - 网格搜索：遍历组合。
  - 随机搜索：随机采样。
  - 贝叶斯优化：概率模型优化。
- **k折交叉验证**：小数据集评估模型性能。

## 12. 快速参考公式
- **Softmax**：$y_i = \frac{e^{z_i}}{\sum e^{z_j}}$
- **Sigmoid**：$\sigma(z) = \frac{1}{1+e^{-z}}$
- **ReLU**：$f(z) = \max(0, z)$
- **梯度更新**：$\theta \leftarrow \theta - \alpha \nabla \mathcal{L}(\theta)$
- **交叉熵**：$\mathcal{L} = -\sum y \log \hat{y}$

## 13. 网络架构选择
- **分类**：更多层和神经元增加容量，注意过拟合。
- **回归**：根据目标函数复杂性选择隐藏层数量。
- **深度 vs 浅层**：深度网络通常更好，但层数过多性能平稳。
