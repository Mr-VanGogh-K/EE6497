## 正面：概率论基础与常用分布

### 1. 概率基础概念
- **随机变量 (RV)**：$p_X(x)$表示概率（pmf离散，pdf连续）。
- **联合、边缘与条件概率**：
  - 联合：$p(x,y)$
  - 边缘：$p(x) = \int p(x,y) \, dy$
  - 条件：$p(y|x) = \frac{p(x,y)}{p(x)}$
  - 贝叶斯定理：$p(x|y) = \frac{p(y|x)p(x)}{p(y)}$
- **独立性**：若$X, Y$独立，则$p(x,y) = p(x)p(y)$。
- **i.i.d.数据集**：$p(D) = \prod_{i=1}^n p(x_i)$，$\log p(D) = \sum_{i=1}^n \log p(x_i)$

### 2. 期望与方差
- **期望**：$E[X] = \int x p(x) \, dx$，$E[X+Y] = E[X] + E[Y]$
- **条件期望**：$E[X|Y=y] = \int x p(x|y) \, dx$
- **方差**：$\text{var}(X) = E[X^2] - E[X]^2$
- **协方差**：$\text{cov}(X,Y) = E[XY] - E[X]E[Y]$
- **向量**：$E[\mathbf{Ax}] = \mathbf{A}E[\mathbf{x}]$，$\text{cov}(\mathbf{x}) = E[\mathbf{xx}^T] - E[\mathbf{x}]E[\mathbf{x}]^T$

### 3. 常用概率分布
| 分布名称          | 概率密度/质量函数                                     | 均值           | 方差             |
|------------------|-----------------------------------------------------|---------------|-----------------|
| 伯努利 (Bern)    |$\text{Bern}(x|\theta) = \theta^x (1-\theta)^{1-x}$,$x \in \{0,1\}$|$\theta$  |$\theta(1-\theta)$|
| 二项 (Bin)       |$\text{Bin}(s|\theta,n) = \binom{n}{s} \theta^s (1-\theta)^{n-s}$|$n\theta$ |$n\theta(1-\theta)$|
| 均匀 (Unif)      |$\text{Unif}(x|a,b) = \frac{1}{b-a}$,$a \leq x \leq b$|$\frac{a+b}{2}$|$\frac{(b-a)^2}{12}$|
| 指数 (Exp)       |$\text{Exp}(x|\lambda) = \lambda e^{-\lambda x}$,$x \geq 0$|$\frac{1}{\lambda}$|$\frac{1}{\lambda^2}$|
| 类别 (Cat)       |$\text{Cat}(x|\theta_1,...,\theta_K) = \theta_x$,$\sum \theta_k = 1$| -             | -               |
| 多项 (Mult)      |$\text{Mult}(s|\theta,n) = \frac{n!}{s_1!...s_K!} \prod \theta_k^{s_k}$| -             | -               |
| 高斯 (Normal)    |$\mathcal{N}(x|\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$|$\mu$    |$\sigma^2$ |

### 4. 共轭分布
- **贝塔 (Beta) 先验 → 二项 (Bin) 似然**：
  - 先验：$\text{Beta}(\theta|a,b) = \frac{\Gamma(a+b)}{\Gamma(a)\Gamma(b)} \theta^{a-1} (1-\theta)^{b-1}$
  - 后验：$p(\theta|s) = \text{Beta}(\theta|s+a, n-s+b)$
- **迪利克雷 (Dir) 先验 → 多项 (Mult) 似然**：
  - 先验：$\text{Dir}(\theta|\alpha_1,...,\alpha_K)$
  - 后验：$p(\theta|s) = \text{Dir}(\theta|s + \alpha)$

### 5. 多元高斯分布
- **定义**：$\mathcal{N}(\mathbf{x}|\boldsymbol{\mu},\mathbf{\Sigma}) = \frac{1}{(2\pi)^{K/2} (\text{det}\mathbf{\Sigma})^{1/2}} \exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^T \mathbf{\Sigma}^{-1} (\mathbf{x}-\boldsymbol{\mu})\right)$
- **性质**：若$X, Y$独立高斯，则$X+Y$也是高斯；线性组合仍是高斯。
- **相关系数**：$\rho_{X,Y} = \frac{\text{cov}(X,Y)}{\sigma_X \sigma_Y}$

## 反面：模型与推断方法

### 1. 机器学习分类
- **监督学习**：学习$Y = f(X)$，基于$D = \{(X_i, Y_i)\}$
  - 分类、目标检测、回归
- **无监督学习**：基于$D = \{X_i\}$，发现结构
  - 聚类、降维、结构学习

### 2. 参数模型与非参数模型
- **参数模型**：固定参数数量，强假设，训练快
  - 似然：$p(x|\theta)$，先验：$p(\theta)$
  - 后验：$p(\theta|x) \propto p(x|\theta) \cdot p(\theta)$
- **非参数模型**：参数随数据增长，灵活，计算复杂

### 3. 矩阵微分公式
-$\frac{\partial (\mathbf{a}^T \mathbf{x})}{\partial \mathbf{x}} = \mathbf{a}$
-$\frac{\partial (\mathbf{x}^T \mathbf{A} \mathbf{x})}{\partial \mathbf{x}} = (\mathbf{A} + \mathbf{A}^T) \mathbf{x}$
-$\frac{\partial (\text{det}(\mathbf{X}))}{\partial \mathbf{X}} = \text{det}(\mathbf{X}) (\mathbf{X}^{-1})^T$

### 5. 模型评估指标
- **拟合优度**：Goodness of Fit
- **分类指标**：精度 (Accuracy), 精确率 (Precision), 召回率 (Recall), F1分数, AUC
- **回归指标**：均方根误差 (RMSE), 平均绝对误差 (MAE)

### 6. 应用案例
- **图神经网络**：非结构化图数据表示学习 (如分子网络)
