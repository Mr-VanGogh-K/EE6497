# 采样（Sampling）Cheat Sheet

## 1. 标准分布采样

### 核心概念
- **目标**：从分布$p(x|\theta)$生成样本以近似期望$\mathbb{E}[f(x)|\theta] \approx \frac{1}{n} \sum_{i=1}^n f(x_i)$（大数定律，SLLN）
- **适用范围**：低维（1或2维）标准分布

### 累积分布函数（CDF）方法
- **原理**：若$F(x) = P(X \leq x)$，则$X = F^{-1}(U)$，其中$U \sim \text{Unif}(0,1)$
- **步骤**：
  1. 生成$U \sim \text{Unif}(0,1)$（Python: `random.random()`）
  2. 计算$X = F^{-1}(U)$
- **示例**：
  - 指数分布$X \sim \text{Exp}(\lambda)$:$X = -\frac{1}{\lambda} \log(1 - U)$
  - 伯努利分布$X \sim \text{Bern}(\theta)$: 若$U \leq 1 - \theta$，$X = 0$，否则$X = 1$

### 变换方法
- **公式**：若$Y = f(X)$，则$p_Y(y) = \sum_{k=1}^K \frac{p_X(x_k)}{|f'(x_k)|}$，其中$x_k$是$f(x) = y$的解
- **示例**：
  - 线性变换$Y = aX + b$:$p_Y(y) = \frac{1}{|a|} p_X\left(\frac{y - b}{a}\right)$
  - 平方变换$Y = X^2$:$p_Y(y) = \frac{1}{2\sqrt{y}} \left( p_X(\sqrt{y}) + p_X(-\sqrt{y}) \right)$

### 复杂分布分解
- **示例**：伽马分布$Y \sim \text{Gamma}(a, b)$（$a$为整数）：$Y = \sum_{i=1}^a X_i$，其中$X_i \sim \text{Exp}(b)$

## 2. 拒绝采样（Rejection Sampling）

### 核心概念
- **目标**：从$p(z) = \frac{1}{M} \tilde{p}(z)$（$M$未知）采样
- **条件**：选择提议分布$q(z)$，需满足$k q(z) \geq \tilde{p}(z)$且$\text{supp } p \subset \text{supp } q$

### 算法步骤
1. 从$q(z)$采样候选值$z$
2. 从$\text{Unif}[0, k q(z)]$采样$u$
3. 若$u \leq \tilde{p}(z)$，接受$z$，否则拒绝

### 接受概率
-$P(\text{z被接受}) = \frac{M}{k}$
- 平均尝试次数：$k$次（$k$尽可能小）

### 应用示例
- **伽马分布**：$p(z) = \text{Gamma}(z|a, b)$，$a$非整数，选择$q(z) = \text{Gamma}(z|c, b-1)$，$c = \lfloor a \rfloor$

## 3. 重要性采样（Importance Sampling）

### 核心概念
- **目标**：计算期望$\mathbb{E}_p[f(z)] = \int f(z) p(z) \, dz$
- **思想**：用易采样分布$q(z)$代替$p(z)$，集中在$|f(z)| p(z)$大的区域

### 基本公式
-$\mathbb{E}_p[f(z)] = \int f(z) \frac{p(z)}{q(z)} q(z) \, dz \approx \frac{1}{n} \sum_{i=1}^n w(z_i) f(z_i)$
- 权重：$w(z) = \frac{p(z)}{q(z)}$
- 条件：$\text{supp } f \cdot p \subset \text{supp } q$

### 归一化权重
- 若$p(z)$、$q(z)$只知未归一化形式：
 $w_n(z_i) = \frac{\tilde{p}(z_i)/\tilde{q}(z_i)}{\sum_j \tilde{p}(z_j)/\tilde{q}(z_j)}$

### 采样-重要性-重采样（SIR）
- **目标**：生成无权重样本
- **步骤**：
  1. 从$q(z)$采样$z_1, \dots, z_n$
  2. 计算归一化权重$w_n(z_i)$
  3. 依据权重从$\{z_1, \dots, z_n\}$重采样
- **应用**：贝叶斯推断中从后验$p(\theta|D)$采样，选择$q(\theta) = p(\theta)$

### 应用示例
- **尾概率估计**：估计$P(X > a)$，选择$q(z)$支持集为$(a, \infty)$

## 4. 关键对比

| **方法**             | **适用场景**                         | **优点**                       | **缺点**                       |
|----------------------|-------------------------------------|-------------------------------|-------------------------------|
| 标准分布采样         | 低维标准分布（均匀、指数等）          | 简单直接                     | 复杂分布需解析解             |
| 拒绝采样             | 未归一化分布$p(z)$             | 无需知道归一化常数           | 接受率低，$k$需大时效率低 |
| 重要性采样           | 计算期望值，稀有事件                 | 提升效率，不拒绝样本         | 依赖$q(z)$选择，收敛慢   |
